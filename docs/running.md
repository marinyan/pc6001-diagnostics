# 実行コマンド

各テストはリセット直後の同じ条件で実施してください。
モード5・画面3ページでCLOAD、WAV再生、読み込み完了後RUN。
一覧が表示されたらEXECを1つだけ入力します。
正常時は番号と縦の印が表示され、印が点滅します。

## F3診断 V3（SRF3V3）

|番号|コマンド|F3への値|意図|
|---|---|---|---|
|1|`EXEC 57344`|書かない|基準|
|2|`EXEC 57347`|00|全ビット0|
|3|`EXEC 57350`|07|下位3つの割込みマスク|
|4|`EXEC 57353`|20|RAMウェイトのビット|
|5|`EXEC 57356`|40|ROMウェイトのビット|
|6|`EXEC 57359`|80|M1ウェイトのビット|
|7|`EXEC 57362`|E0|上位3ビット|
|8|`EXEC 57365`|E7|ローダー初期化時の設定|
|9|`EXEC 57368`|E6|ローダー受信時の設定|

値は16進数。説明は既存のmkII向け資料・エミュレータの解釈に基づき、
SR実機で同じかを検証しています。読み出し値にORせず固定値を書きます。
全テストDIのままで割込み処理は実行しません。
優先順は1→2→4～6。時間がなければ1件だけの報告でも構いません。
C6/C7との比較は次の候補であり、V3にはまだ含まれません。

## ポート別 V2（SRPORT）

|番号|コマンド|設定|
|---|---|---|
|1|`EXEC 57344`|画面設定のみ|<-成功を確認済
|2|`EXEC 57347`|F3=E7だけ追加|<-失敗を確認済
|3|`EXEC 57350`|F8=00だけ追加|
|4|`EXEC 57353`|F2=55だけ追加|
|5|`EXEC 57356`|F3=E7→F8=00→F2=55|

## 初期診断（SRDIAG）

|番号|コマンド|設定|
|---|---|---|
|1|`EXEC 57344`|画面設定のみ|<-成功を確認済
|2|`EXEC 57347`|F3/F8/F2追加|<-失敗を確認済
|3|`EXEC 57350`|2にF0/F1=DD追加|←以下確認不要
|4|`EXEC 57353`|3にPPI初期化追加|
|5|`EXEC 57356`|旧P60GUE LOADER V2の画面初期化|

5のWAIT HEADERは文字表示だけで、受信は行いません。

## 読み込みと実行の失敗を分ける

- `Found:`が出ない：診断の実行前。再生開始位置・接続・音量を確認。
- CLOADのエラー：診断の実行前。結果表では「ロード失敗」とする。
- RUNでFCエラー：機械語コピー未完了。テスト結果として扱わない。
- EXEC後の黒画面：そのテスト番号で報告。ただしCPU停止とは断定しない。
- 表示あり・点滅なし：表示あり・点滅なしとして報告。

音量を上げすぎると歪むことがあります。以前読めたWAVとの同一条件での比較が有用です。
