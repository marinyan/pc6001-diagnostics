# Project scope

This repository contains standalone PC-6001-series diagnostics, not the P60GUE game.
Keep hardware reports, emulator observations, and hypotheses separate.
Do not publish ROM images, emulator sessions/tokens, or machine-specific paths.
Published test numbers and filenames identify fixed experiments; use a new version
when changing their meaning. Keep all generated distribution files and manifest in sync.
Run npm run build with sjasmplus 1.24.0, then npm test for distribution changes.
Emulator success does not establish real-hardware compatibility.
